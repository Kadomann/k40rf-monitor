Gateway finden

Die App sucht im WLAN nach deinem Connect-Key K 40 RF. Dein Gerät muss im selben Netzwerk sein wie die Heizung.

    Steht in der Geräteliste deines Routers.

    Zugangsdaten

    Login und Pass stehen auf dem Aufkleber am Gateway.

    Ich habe schon einen Token

    Zum Beispiel von der Einrichtung auf einem anderen Gerät. So wird kein neuer Token auf dem Gateway verbraucht.

    Gateway koppeln

    1. Geh zum Gateway.
    2. Drück die WLAN-Taste und die Funk-Taste gleichzeitig etwa eine Sekunde lang.
    3. Die LEDs blinken kurz blau.
    4. Tipp innerhalb von 5 Minuten auf „Koppeln“.

    Anlage erkunden

    Bewahr ihn sicher auf, etwa im Passwortmanager. Damit richtest du weitere Geräte ein, ohne einen neuen Token zu verbrauchen; der Speicher des Gateways ist begrenzt.
